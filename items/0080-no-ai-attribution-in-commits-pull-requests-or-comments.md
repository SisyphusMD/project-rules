# #80 No AI attribution in commits, pull requests or comments

- Kind: issue, state: closed, by cody, created 2026-11-17T09:03:26-08:00
- Labels: status:in-progress, type:feature; milestone: none

Decision (Cody, 2026-11-17): like the SparkyFitness rule, contributions carry no AI attribution anywhere. No Co-Authored-By trailer for an assistant, no 'Generated with ...' line, no robot emoji and no AI tool named as an author, in commit messages, PR titles and descriptions, or comments. Add it to RULES.md (rule 9, so rule numbers others cite stay put) and the CONTRIBUTING template, and to each repo's CONTRIBUTING as it adopts the rules.
